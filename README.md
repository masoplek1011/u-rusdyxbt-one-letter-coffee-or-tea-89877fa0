# One Letter: Coffee or Tea

An entry for the [make.fun](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) competition "One Letter: Coffee or Tea".

The program writes exactly one letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` — **A for coffee** — one byte, no newline, no explanation. Coffee is the more vivid, funnier and truer answer: black, bitter, steaming, the jolt that drags a person awake in the morning, and the honest confession that nobody is really a person until the first cup.

## Run

```sh
node main.ts
```

This writes `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Requires Node 22.18 or later; standard library only, deterministic.
